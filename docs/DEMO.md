# Демонстрация Docere за 5–7 минут

## Подготовка

```bash
docker compose up -d --build
docker compose run --rm api migrate
docker compose run --rm -v "$(pwd):/demo" api seed-demo --archive-output /demo/docere-demo-archive.zip
```

Откройте [http://localhost:8000](http://localhost:8000) и войдите как `dr.sokolov@docere.demo` с паролем
`DemoPass123`.

## Сценарий

1. **Рабочее место врача — 30 секунд.** Покажите реальные карточки пациентов, входящие sharing-запросы и последние импорты.
2. **Загрузка — 30 секунд.** Откройте «Импорт архива», загрузите `docere-demo-archive.zip` и обратите внимание на фоновый статус задания.
3. **Безопасный разбор — 45 секунд.** После перехода в review покажите отклонённый небезопасный путь, пустой файл и объединённые DICOM-файлы.
4. **Решения врача — 2 минуты.** Сопоставьте Иванова с существующей картой, оставьте Орлову новой карточкой, выберите предложенную дату и явно решите вопрос потенциального дубля.
5. **Возобновление — 30 секунд.** Обновите страницу и покажите, что review-черновик восстановился; статус автосохранения расположен под заголовком.
6. **Resolve — 1 минута.** Проверьте итоговые счётчики, подтвердите состав импорта и дождитесь завершения задания.
7. **Provenance — 1 минута.** Перейдите по ссылке результата в медицинскую историю: созданная запись открывается сразу и показывает исходный архив, import job и количество файлов.
8. **Sharing и аудит — 1 минута.** Выберите запись для sharing, затем покажите исходящий запрос и соответствующие события в административном журнале.

Архив полностью синтетический. Команда `seed-demo` очищает прикладные таблицы и предназначена только для локального или демонстрационного окружения.
