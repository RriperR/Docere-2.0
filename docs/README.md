# Документация Docere

Если вы впервые открыли репозиторий, начните с [основного README](../README.md).
Ниже документы разделены по задаче читателя. Описание возможности и инструкция запуска
имеют разные источники истины; исторический отчёт не заменяет актуальную инструкцию.

| Хочу | Открыть |
|---|---|
| Увидеть, как пользоваться системой | [Экскурсия по продукту](PRODUCT-TOUR.md) — текущие экраны и действия |
| Запустить демонстрацию | [DEMO.md](DEMO.md) — стенд, синтетические аккаунты, подготовка данных |
| Провести презентацию | [DEMO-PRESENTER.md](DEMO-PRESENTER.md) — короткий маршрут и реплики |
| Разрабатывать или обновить окружение | [DEVELOPMENT.md](DEVELOPMENT.md) — запуск, миграции, проверки |
| Подключить внешний AI | [AI.md](AI.md) — конфигурация, ограничения и проверка подключения |
| Разобраться в коде и доступе | [ARCHITECTURE.md](../ARCHITECTURE.md) — слои, инварианты и API-потоки |
| Внести изменение | [CONTRIBUTING.md](../CONTRIBUTING.md), [AGENTS.md](../AGENTS.md) |
| Подготовить внешнее окружение | [PILOT.md](PILOT.md), [SECURITY.md](SECURITY.md) |
| Повторить программные проверки | [VALIDATION.md](VALIDATION.md) — команды и датированные измерения |
| Проверить востребованность у врачей | [PRODUCT-VALIDATION.md](PRODUCT-VALIDATION.md) — протокол, результаты пока не собраны |
| Подготовить ВКР | [THESIS.md](THESIS.md) — тема, архитектурные и экспериментальные материалы |

## Планы и история

- [UX-план и статус реализации](UX-IMPROVEMENT-PLAN.md) — проблемы интерфейса, принятые решения,
  выполненные пакеты и оставшаяся проверка с врачами.
- [Инженерный backlog](roadmap/README.md) и [его реестр](roadmap/STATUS.md) — отдельные задачи
  масштабирования, доступа, эксплуатации и AI-оценки. Статус конкретной задачи проверяйте по реестру;
  он не означает, что весь backlog входит в текущий UI-пакет.
- [Отчёты ревью](reviews/README.md) — датированные свидетельства прошлых проверок.
  Число тестов, внешний вид и оценки безопасности в них относятся к указанному commit.
- [Архив](archive/README.md) — старые планы и спецификации; не инструкции для новых изменений.

Скриншоты экскурсии используют только синтетические данные. Локальные логины, ссылки на
конкретный случай и тексты для показа создаются в `artifacts/product-demo/<run>/OPEN-ME.md`;
эта папка не входит в Git и её содержимое не является частью публичной документации.
