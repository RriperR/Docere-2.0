# Архив проектных документов

В этом каталоге хранятся исторические документы раннего этапа разработки:

- `PRD-Docere-2026-02-20.md` - исходная версия продуктовых требований;
- `tasks.json` - завершённый план задач агента;
- `progress.md` - журнал выполнения этих задач.

Документы сохранены для контекста и трассировки решений, но больше не являются актуальными инструкциями или источником истины.

Текущие документы проекта:

- продукт и запуск - [`README.md`](../../README.md);
- техническая архитектура и компромиссы - [`ARCHITECTURE.md`](../../ARCHITECTURE.md);
- процесс разработки - [`CONTRIBUTING.md`](../../CONTRIBUTING.md);
- инструкции для coding agents - [`AGENTS.md`](../../AGENTS.md).
