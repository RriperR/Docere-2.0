# Завершение UX-пакета — 24 октября 2026

Реализация: commit `ebe4300`. Область: UX-03, UX-04 и правила UX-05 для затронутых экранов. UX-01/02 завершены ранее
в commit `58c503f`; базовая тема и навигация — `22012be`. Отчёт фиксирует этот пакет,
не заменяет текущую [экскурсию](../PRODUCT-TOUR.md).

## Поведение

- Входящая задача открывает конкретный запрос мнения с источником и формой ответа.
  Другой черновик не переназначается молча; обычная реплика и связанный ответ имеют разные действия.
- Фильтры раскрываются с количеством условий, журнал и предыдущие версии — по запросу.
  Последний итог виден отдельно от истории версий с серверной пагинацией.
- Основное действие итога соответствует шагу: сохранить, завершить, опубликовать.
  Отличающийся черновик, открытые запросы и дата публикации требуют явного решения.
- Основные разделы навигации отделены от передачи записей и заявок врачей.
  История пациента и её основные действия видны раньше технических деталей.
- Статус подтверждения не смешивается с происхождением доступа. Внутренний ZIP и UUID
  убраны из основных карточек; технические детали доступны в раскрываемых блоках.
- README стал коротким знакомством. Запуск, AI, экскурсия, выступление и история проверок
  имеют отдельные документы и общую карту навигации.

## Реальный браузерный прогон

Отдельный синтетический набор создан публичным API, без reset и внешних AI-вызовов.
Два независимых браузерных контекста прошли входящие, материал, адресованный ответ,
сохранение итога, закрытие и публикацию через UI. Результат опубликован с датой
`2026-10-24`, остался неподтверждённым и открывался адресной ссылкой на запись.

Посторонний врач не получил случай, сообщения, запросы, итог и материалы через прямые API.
Опубликованная запись не выдана участнику автоматически. После исключения участника из
закрытого случая исходный файл стал недоступен, перезагрузка скрыла клинический текст;
у координатора опубликованная запись сохранилась.

Управляемый ответ `503` при отправке обычного сообщения сохранил текст. Повтор через
настоящий API с тем же ключом завершился успешно. Это проверка UI-поведения при ошибке,
а не имитация реального отказа инфраструктуры.

Проверены обе темы на 390/768/1440 px, отсутствие горизонтального переполнения,
Escape и возврат фокуса мобильной навигации. Анимации завершались до снятия скриншотов.
Сохранённые локальные trace/results находятся в игнорируемом `artifacts/ux-final-20261024`;
в Git включены только синтетические скриншоты, используемые экскурсией.

## Автоматические проверки и ограничения

Frontend: 123 Vitest-теста, TypeScript, production build и ESLint.
Обновлены существующие E2E для новых подписей и проверки одного документа;
сценарий `e2e/product-demo.spec.ts` прошёл на новом синтетическом наборе (1 passed).
Полный контейнерный набор с seed-аккаунтами и тестовым AI-адаптером заново не запускался.
Отдельный браузерный сценарий выше прошёл на реальном локальном API.
Backend-код и миграции не менялись; полный backend gate в этом UI-пакете не запускался.

Не воспроизводились заново реальное истечение JWT, все варианты DICOM/PDF,
полный аудит WCAG и нативный browser zoom. Более ранняя проверка reflow использовала
эквивалентную ширину 720 CSS px на 1440 физических px. Исследование с реальными врачами
подготовлено в [PRODUCT-VALIDATION.md](../PRODUCT-VALIDATION.md), но участников и результатов ещё нет.
