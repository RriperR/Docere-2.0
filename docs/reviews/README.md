# Датированные отчёты проверок

Эти файлы сохраняют решения, результаты и ограничения на момент конкретного изменения.
Они не являются текущей инструкцией использования и не доказывают состояние следующего commit.
Актуальный продукт: [экскурсия](../PRODUCT-TOUR.md); команды проверки: [VALIDATION.md](../VALIDATION.md).

Файлы с датой фиксируют соответствующий прогон; отчёты `onboarding-*`, `history-pagination-b1`,
`product-*`, `import-ai-evaluation-e2` связаны с задачами [инженерного backlog](../roadmap/STATUS.md).
Новые измерения добавляйте отдельным отчётом с commit, окружением, командой и границами проверки.
